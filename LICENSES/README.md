# Lisensi dan attribution

Source BYGA pada rilis ini tidak menyertakan source yang disalin dari empat referensi upstream. Referensi, penulis/repositori, SHA, lisensi, dan keputusan integrasi dicatat pada `docs/UPSTREAM_AUDIT.md`.

Dependency npm/Go tetap tunduk pada lisensi paket masing-masing. SBOM rilis mencatat versi aktual; teks lisensi paket tetap tersedia pada distribusi dependency. Tidak menetapkan lisensi baru untuk repository milik pengguna tanpa pilihan eksplisit pemilik.
